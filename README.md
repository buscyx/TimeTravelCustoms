# 🚀 Douane Temporelle (Time Travel Customs)

## 📌 Description

Douane Temporelle is a mobile application that simulates a customs checkpoint for time travelers. Users can register their information, undergo a paradox risk inspection, and receive a final decision about their time travel authorization.

## ✨ Features

- **Traveler Registration:** Enter name, birth year, destination year, and travel reason.
- **Paradox Scanner:** Display traveler information in a passport-style interface.
- **Time Travel Approval:** Approve or reject the travel request.
- **Paradox Detection:** Automatically disable approval if the travel reason is "Modification du passé" and the time difference is a prime number.
- **Final Verdict:** Display a personalized approval or arrest message.
- **New Traveler:** Start a new registration.

## 🛠️ Technologies

- Java
- Android Studio
- XML
- Android Intents

## 📂 Activities

| Activity | Description |
|---|---|
| `MainActivity` | Traveler registration form |
| `VerificationActivity` | Paradox scanner and verification |
| `ResultActivity` | Final verdict and result |
